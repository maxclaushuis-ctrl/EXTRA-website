# Experimenteren met EXTRAATJE Test Environment

## Hoe je experimenten kunt doen

### Optie 1: Nieuwe Browser Tab
1. Open een nieuw tabblad in je browser
2. Ga naar dezelfde URL als de huidige app
3. Je hebt nu twee instances van dezelfde app die onafhankelijk werken

### Optie 2: Incognito/Private Mode
1. Open een incognito venster
2. Ga naar de app URL
3. Test nieuwe features zonder je huidige sessie te beïnvloeden

### Optie 3: Test met Verschillende Gebruikers
- **Medewerker**: `medewerker@extra.nl` / `password123`
- **Admin**: `admin@extra.nl` / `admin123`
- **Test Users**: `piet@extra.nl`, `maria@extra.nl`, `jan@extra.nl` / allemaal `password123`

## Wat je kunt testen

### Leaderboard Features
- Rankings en position badges
- Monthly points tracking
- Real-time updates via WebSocket

### Challenges Systeem
- Progressive challenges met steps
- One-time challenges
- Manual progress updates (als admin)

### Rewards & Discounts
- Beloning verzilvering
- Kortingscode kopiëren
- Vereenvoudigde deals interface

### Admin Panel
- Challenge management
- User progress tracking
- Point transactions

## Database State
De test data blijft behouden tussen browser sessions, dus je experimenten worden niet gereset tenzij de server opnieuw start.

## Nieuwe Features Testen
Als je wilt experimenteren met nieuwe gamification features, laat me dan weten welke richting je op wilt:

1. **Social Features**: Team challenges, activity feeds, social achievements
2. **Advanced Tracking**: Streak counters, performance analytics, goal setting
3. **Motivation Psychology**: Surprise bonuses, milestone celebrations, FOMO elements
4. **Business Integration**: Client feedback, availability rewards, skill development

Je kunt in de huidige app alle bestaande features testen en feedback geven over welke uitbreidingen je interessant vindt.
