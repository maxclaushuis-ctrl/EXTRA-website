Vacature CMS + SEO vacaturestructuur
You are a senior product designer, UX designer, front-end developer and SEO strategist working on the EXTRA website and dashboard environment.
Your task is to create a Vacancy Management System inside the /dashboard-mockup admin environment, similar to the existing “Blogs & SEO” section.
This system will allow internal staff to create, manage and publish vacancies, while automatically generating SEO-optimized vacancy pages that follow a consistent structure across the website.
The system must ensure:
• easy vacancy management for internal users
• a consistent design across all vacancy pages
• SEO-optimized page structures by default
• automatic internal linking
• a scalable architecture for future vacancies

8 Dynamic internal linking system
Each vacancy page must automatically include internal links to relevant pages within the website to strengthen SEO and site structure.
Do NOT hardcode URLs.
Instead, dynamically detect and link to relevant existing pages.
Use the following logic:
Step 1
Identify the main candidate journey page where visitors learn how working via EXTRA works or can sign up.
Step 2
Identify job category pages related to the vacancy type.
Examples:
• horeca work pages
• chef work pages
• housekeeping work pages
• front office work pages
Step 3
Identify other relevant work pages or job categories within the site structure.
Linking logic
For each vacancy page automatically generate links to:
• the main candidate journey page
• the relevant job category page
• related job category pages where relevant
Example logic:
If vacancy category = Chef
→ link to the chef category page
If vacancy category = Housekeeping
→ link to the housekeeping work page
Dynamic detection
The system should:
• scan the existing site structure
• detect relevant pages
• generate contextual links
Do not rely on fixed URLs.
Use page identifiers, categories or page types.
This ensures links remain correct if page URLs change.
9 Internal linking placement
