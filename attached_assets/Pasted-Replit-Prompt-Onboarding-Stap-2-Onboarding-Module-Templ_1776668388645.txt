Replit Prompt — Onboarding Stap 2: Onboarding Module & Template Beheer
Wat je gaat doen
Bouw een "Onboarding" pagina bereikbaar via de CAMPAGNES sectie in de navigatie. Dit is de centrale plek voor het beheren van onboarding e-mail templates, bijlagen en statistieken. De editor is dezelfde als die van de klantcampagnes, maar toegespitst op medewerker-onboarding. Templates zijn instelbaar per taal, functie en opdrachtgever.

2. Database schema
sqlCREATE TABLE IF NOT EXISTS onboarding_templates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  naam TEXT NOT NULL,
  taal TEXT DEFAULT 'Nederlands',      -- opties: Nederlands, Engels
  functiegroep TEXT,                   -- leeg = alle functies
  opdrachtgever TEXT,                  -- leeg = alle opdrachtgevers
  onderwerp TEXT NOT NULL,
  content TEXT,                        -- JSON van e-mailblokken
  is_standaard INTEGER DEFAULT 0,      -- 1 = standaard fallback voor deze taal
  actief INTEGER DEFAULT 1,
  aangemaakt_op DATETIME DEFAULT CURRENT_TIMESTAMP,
  bijgewerkt_op DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS onboarding_bijlagen (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  naam TEXT NOT NULL,
  bestandsnaam TEXT NOT NULL,
  bestandspad TEXT NOT NULL,
  bestandsgrootte INTEGER,
  taal TEXT DEFAULT 'alles',           -- opties: alles, Nederlands, Engels
  versie TEXT,
  actief INTEGER DEFAULT 1,
  geupload_op DATETIME DEFAULT CURRENT_TIMESTAMP,
  bijgewerkt_op DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS onboarding_template_bijlagen (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  template_id INTEGER NOT NULL,
  bijlage_id INTEGER NOT NULL,
  volgorde INTEGER DEFAULT 0,
  FOREIGN KEY (template_id) REFERENCES onboarding_templates(id),
  FOREIGN KEY (bijlage_id) REFERENCES onboarding_bijlagen(id)
);

6. Template selectie logica
Bouw een functie selecteerOnboardingTemplate(medewerker) die de best passende template selecteert van meest naar minst specifiek:
javascriptasync function selecteerOnboardingTemplate(medewerker) {
  const { taal, functie, opdrachtgever } = medewerker;
  const kandidaten = await getTemplates({ actief: 1 });

  return (
    // 1. Opdrachtgever + functie + taal (meest specifiek)
    kandidaten.find(t =>
      t.opdrachtgever === opdrachtgever &&
      t.functiegroep === functie &&
      t.taal === taal
    ) ||
    // 2. Opdrachtgever + taal
    kandidaten.find(t =>
      t.opdrachtgever === opdrachtgever &&
      !t.functiegroep &&
      t.taal === taal
    ) ||
    // 3. Functie + taal
    kandidaten.find(t =>
      !t.opdrachtgever &&
      t.functiegroep === functie &&
      t.taal === taal
    ) ||
    // 4. Standaard voor deze taal
    kandidaten.find(t =>
      !t.opdrachtgever &&
      !t.functiegroep &&
      t.taal === taal &&
      t.is_standaard === 1
    ) ||
    // 5. Nederlandse standaard (ultieme fallback)
    kandidaten.find(t =>
      t.taal === 'Nederlands' &&
      t.is_standaard === 1
    )
  );
}

10. API endpoints
Templates

GET /api/onboarding/templates — alle templates, filterbaar op taal, functiegroep, opdrachtgever, actief
GET /api/onboarding/templates/:id — volledig inclusief gekoppelde bijlagen
POST /api/onboarding/templates — nieuwe template aanmaken
PUT /api/onboarding/templates/:id — updaten inclusief content
DELETE /api/onboarding/templates/:id — verwijderen
GET /api/onboarding/templates/selecteer?taal=&functie=&opdrachtgever= — beste match teruggeven op basis van selectielogica

Bijlagen

POST /api/onboarding/bijlagen — multipart upload
GET /api/onboarding/bijlagen — lijst, filterbaar op taal en actief
GET /api/onboarding/bijlagen/:id/bekijken — PDF in browser (Content-Type: application/pdf, Content-Disposition: inline)
PUT /api/onboarding/bijlagen/:id/vervangen — nieuwe versie uploaden
DELETE /api/onboarding/bijlagen/:id — verwijderen met koppelingscheck

Koppelingen

POST /api/onboarding/template-bijlagen — bijlage aan template koppelen, body: { template_id, bijlage_id, volgorde }
DELETE /api/onboarding/template-bijlagen/:id — bijlage loskoppelen

Statistieken

GET /api/onboarding/statistieken — KPI's + laatste 50 verzendingen
GET /api/onboarding/statistieken/export/csv — CSV export
