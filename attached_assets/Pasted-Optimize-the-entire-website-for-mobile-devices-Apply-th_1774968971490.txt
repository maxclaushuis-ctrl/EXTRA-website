## FILE 1: client/index.html

### Problem 1: Double font loading
The fonts are loaded twice: once via @import in index.css, and once via the preload link in index.html. This wastes bandwidth on mobile.

Remove the preload link and its noscript fallback entirely:
  <link rel="preload" href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=Poppins:wght@400;600;700;800;900&display=swap" as="style" onload="this.onload=null;this.rel='stylesheet'" />
  <noscript><link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=Poppins:wght@400;600;700;800;900&display=swap" rel="stylesheet" /></noscript>

Keep the two preconnect lines. The fonts will still load via index.css @import.

### Problem 2: Dev-only scripts loading in production
The following two scripts should never load in production. Remove both lines:
  <script src="/suppress-hmr-errors.js"></script>
  <script type="text/javascript" src="https://replit.com/public/js/replit-dev-banner.js"></script>

### Problem 3: Viewport missing user-scalable setting and maximum-scale
Change:
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
To:
  <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />

### Problem 4: Missing dns-prefetch for external services
After the two preconnect lines, add:
  <link rel="dns-prefetch" href="https://cdn.platform.jobster.com" />
