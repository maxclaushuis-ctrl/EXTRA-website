ROLE
You are a senior product design + engineering team (UX, UI, SEO, performance) building the optimized HOMEPAGE for EXTRA (Dutch hospitality staffing agency). You must improve conversion, clarity, and credibility for two audiences: (1) employers seeking staff and (2) job seekers seeking work. Build a visually striking but highly readable page, with subtle motion and excellent performance.

LANGUAGE & TONE (EXTRA)
- Language: Dutch.
- Voice: jong, direct, professioneel, licht speels. Korte zinnen. Geen wollige claims.
- Always use “je/jij/jouw” (never “u”).
- Use “EXTRA” naturally in headings/CTA’s where it strengthens the brand (no forced repetition).
- Headings style: only the first word starts with a capital letter, rest lowercase (e.g., “Extra personeel per sector”).

TECH STACK
- Next.js (App Router) + TypeScript + Tailwind CSS.
- Use component-based architecture with clean folder structure.
- Use next/image for all images, optimize sizes, lazy-load below fold.
- Add Framer Motion for subtle animations; respect prefers-reduced-motion.
- Accessibility: semantic HTML, keyboard navigation, focus states, skip-to-content.
- Performance: aim for fast LCP; avoid heavy JS; keep animations lightweight.

SEO REQUIREMENTS (2026-proof)
- Exactly ONE H1 on the page.
- Clear H2/H3 hierarchy per section.
- Meta title (≤60 chars) + meta description (155–160 chars).
- OpenGraph/Twitter tags.
- JSON-LD: Organization + WebSite + FAQPage (4 FAQs at bottom).
- Image alt texts (descriptive, no keyword stuffing).
- Internal links to key pages: /werkgevers, /werkzoekenden, sector pages, /extraatje, /cases, /kennisbank, /contact.

DESIGN SYSTEM (VISUAL)
- Style: premium, modern, bold. “EXTRA” can be visually loud, but content stays clean.
- Background: signature purple gradient + subtle “X” shapes with low opacity + soft noise texture.
- Layout: consistent max-width container; strong vertical rhythm; less empty whitespace than current.
- Buttons: consistent system (primary = high contrast, secondary = outlined).
- Cards: soft shadow, rounded corners, subtle border. Glass effect only where it improves readability.
- Motion: gentle scroll reveal, hover micro-interactions, counters on in-view. No distracting movement.

NAVIGATION (STICKY)
- Left: EXTRA logo.
- Right (desktop): Hoe het werkt, Waarom extra, Extraatje, Werkgevers, Werkzoekenden + primary button “Contact”.
- Sticky navbar with backdrop blur and subtle shadow after scroll.
- On mobile: hamburger menu + persistent “Contact” or primary CTA.
